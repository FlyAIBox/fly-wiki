# 网页采集与 Editable Note 验收

前置：核心 Compose 已启动，`http://localhost:8000/health/ready` 返回 `ready`。

## 1. 读取默认上下文

```bash
CTX=$(curl -fsS http://localhost:8000/api/context)
WS=$(echo "$CTX" | jq -r .workspace_id)
KB=$(echo "$CTX" | jq -r .knowledge_base_id)
HEADER="X-Workspace-ID: $WS"
```

## 2. 提交公开网页

```bash
KEY="manual:$(date +%s)"
JOB=$(curl -fsS -X POST \
  -H "$HEADER" \
  -H "Content-Type: application/json" \
  -d "{\"url\":\"https://example.com/\",\"idempotency_key\":\"$KEY\"}" \
  "http://localhost:8000/api/workspaces/$WS/knowledge-bases/$KB/captures")
echo "$JOB" | jq
JOB_ID=$(echo "$JOB" | jq -r .id)
```

期望：HTTP 202，状态为 `accepted`，立即返回稳定 `id`。

用完全相同的 URL 和 `idempotency_key` 再提交一次，期望返回同一个 `id`，不会重复派发任务。

## 3. 查询进度

```bash
curl -fsS -H "$HEADER" \
  "http://localhost:8000/api/workspaces/$WS/captures/$JOB_ID" | jq
```

状态依次为 `accepted` → `fetching` → `ready_for_compile`。失败时为 `failed`，并包含稳定的 `error_code`；最多可手动重试三次：

```bash
curl -fsS -X POST -H "$HEADER" \
  "http://localhost:8000/api/workspaces/$WS/captures/$JOB_ID/retry" | jq
```

## 4. 查看不可变 Source Version

```bash
JOB=$(curl -fsS -H "$HEADER" \
  "http://localhost:8000/api/workspaces/$WS/captures/$JOB_ID")
SV=$(echo "$JOB" | jq -r .source_version_id)
VERSION=$(curl -fsS -H "$HEADER" \
  "http://localhost:8000/api/workspaces/$WS/source-versions/$SV")
echo "$VERSION" | jq
```

期望：

- 包含 `raw_html`、`markdown`、`metadata`、`locator_map` 四类 Artifact；
- `editable_note_id` 非空；
- 相同内容用新幂等键重新采集时复用 Source Version；网页内容变化时创建新版本。

下载原始 HTML：

```bash
ARTIFACT=$(echo "$VERSION" | jq -r '.artifacts[] | select(.role=="raw_html") | .id')
curl -fsS -H "$HEADER" \
  "http://localhost:8000/api/workspaces/$WS/source-versions/$SV/artifacts/$ARTIFACT"
```

## 5. 编辑并版本化 Note

```bash
NOTE=$(echo "$VERSION" | jq -r .editable_note_id)
curl -fsS -H "$HEADER" \
  "http://localhost:8000/api/workspaces/$WS/editable-notes/$NOTE" | jq

curl -fsS -X PUT \
  -H "$HEADER" \
  -H "Content-Type: application/json" \
  -d '{"markdown":"# 手工编辑\n","base_version_number":1}' \
  "http://localhost:8000/api/workspaces/$WS/editable-notes/$NOTE" | jq
```

期望：历史包含版本 1、2，当前版本为 2；Source Version 的 `content_sha256` 保持不变。再次以 `base_version_number: 1` 保存应返回 HTTP 409，防止覆盖并发编辑。

## 安全抽查

- 缺少 `X-Workspace-ID`：HTTP 400；
- Header 与路径 Workspace 不一致：HTTP 403；
- 其他 Workspace 的 Job、Source Version、Artifact、Note：统一 HTTP 404；
- `localhost`、内网 IP、非 HTTP(S) URL：采集失败且 `error_code=unsafe_url`；
- 非 HTML 或超过 `FLYWIKI_CAPTURE_MAX_BYTES` 的响应：采集失败。
