# App 目标：当前不派本地 case

> 仅当本轮验证问题的 primary surface 是 Android、iOS 或 mac 原生应用 `app` 时读取本页。命中后停止组装本地 persona、Methodology 与 case，直接报告 execution limitation。

## 当前边界（2026-08-04，#498）

**App 界面驱动已退役，这一族的 case 一律不派。** GUI 控制已经交给 pi-gui，原 simulator MCP 注入整条撤走；残留 CLI 只有坐标级动作，不能提供按可见文字定位的 ref。pi-gui 当前又是把整项 GUI 任务委派给另一个代理，只返回纯文本与 session key，无法让 eval 子代理自己逐步行动并留下可核验的 ref + 截图证据链。

遇到 App 目标时，如实告诉用户暂无合规真实入口。拿不到入口不是失败，冒充拿到了才是。

## 禁止的替代

1. **不许用坐标点击凑 case。** 截图不能证明坐标实际点中了用户所见的控件。
2. **不许拿网页版冒充 App。** 真要评网页版，必须把 primary surface 改为 `web`，重写验证问题和结论边界。
3. **不许驱动用户自己的浏览器或应用。** 用户的登录态、历史、焦点与隐私不能成为测试夹具。
4. **不许读源码或静态截图后声称真实操作已通过。** 可做更窄的内容/像素检查，但必须改成对应目标。

## 恢复派发的门槛

只有以下四项同时成立才恢复 App case：子代理能自己逐步驱动；每步拿到带可见文字的 ref；每次操作后截图能落入 evidence；每个 case 有独立设备或独立初态。缺一项就仍只报告 execution limitation。
